# Цели Яндекс Метрики

Счётчик: **110816502** (zeip.ru)

Инициализация — только после принятия cookie-согласия (`CookieBanner`).
Все вызовы идут через `reachYandexMetrikaGoal(goal, params?)` из `my-app/src/lib/yandexMetrika.ts`.

### 3. Клик по пейволлам → тарифы

| Параметр | Значение |
|---|---|
| Идентификатор | `paywall_cta_buy` |
| ID в Метрике | 600742104 |
| Где вызывается | `my-app/src/lib/paywallAnalytics.ts` → `trackPaywallCtaBuy(intent)` |
| Когда | Клик CTA «Выбрать тариф» в `PaywallDrawer`; клик «Оформить Pro / Pro+» в композере ЛС / общего чата |
| Параметры | нет (intent зашит в имя параллельной цели `paywall_cta_buy_{intent}`) |

Пейволл открывается из разных контекстов (`intent`):

| intent | Триггер |
|---|---|
| `dm` | Попытка написать сообщение |
| `chat` | Открытие чата |
| `pin` | Добавление пина |
| `banner` | Клик на баннере карты (если откроется через DrawerPaywall) |
| `view_limit` | Превышен лимит просмотров профилей |
| `favorites_limit` | Превышен лимит избранного |

### 4. Переход на страницу оплаты

| Параметр | Значение |
|---|---|
| Идентификатор | `checkout_started` |
| ID в Метрике | 600742044 |
| Где вызывается | (1) `paywallAnalytics.ts` → `trackCheckoutStarted()` (`PaywallDrawer`, CTA композера) · (2) `SubscriptionPlansView.tsx` → `handleBuy()` |
| Когда | (1) Клик «Выбрать тариф» в `PaywallDrawer` · (2) Клик «Оформить Pro / Pro+» в композере чата · (3) Клик «Оформить» на странице `/subscription` |
| Параметры | (1) нет — тариф ещё не выбран · (2) `{ plan, period, price, currency: "RUB" }` |

> **Важно:** в `PaywallDrawer` и `SubscriptionPlansView` перед `window.location.href` стоит `setTimeout 300мс` — это даёт Метрике время отправить beacon до hard navigation. Без задержки цель может не фиксироваться.

---

### 5. Оплата

| Параметр | Значение |
|---|---|
| Идентификатор | `payment_success_activated` |
| ID в Метрике | 600742237 |
| Где вызывается | `my-app/src/components/PaymentSuccessView.tsx` → `finishSuccess()` |
| Когда | Подписка фактически активирована в БД (polling подтвердил `isPro: true`) |
| Параметры | `{ order_price: number, currency: "RUB" }` — если `OutSum` есть в URL от Robokassa |

> Сумма берётся из URL-параметра `OutSum`, который Robokassa передаёт при редиректе на `/payment/success`. Если пользователь перезагрузил страницу — параметр пропадает, цель всё равно срабатывает без суммы.

---

### 6. Прохождение квиз-онбординга (воронка)

Онбординг — 4 шага, каждый фиксируется отдельной целью. Все вызовы в `my-app/src/app/onboarding/page.tsx` → `saveCurrentStepData()`.

> UI может показать следующий шаг до завершения persist (optimistic transition), но **`reachGoal` по-прежнему только после успешной записи в БД** — идентификаторы и воронка не меняются.

| Идентификатор | Шаг | Когда срабатывает |
|---|---|---|
| `onboarding_step_1` | «Расскажите о себе» | После успешного persist имени, возраста, города (UI шага 2 может быть уже виден) |
| `onboarding_step_2` | «Профессия и отрасль» | После успешного persist профессии, отрасли, статуса |
| `onboarding_step_3` | «Интересы и о себе» | После успешного persist навыков, интересов, ресурсов |
| `onboarding_step_4` | «Ваша точка на карте» | После сохранения геопозиции |
| `onboarding_complete` | Финал | Сразу после `onboarding_step_4`, когда `onboarding_completed: true` записан в БД |

Параметры `onboarding_complete`: `{ city: string }` — город пользователя для сегментации.

ID в Метрике: `onboarding_complete` — 600741845. Цели `onboarding_step_1..4` создать в интерфейсе Метрики вручную (тип — JavaScript-событие, идентификатор точный).

## Воронка в отчёте «Воронки»

Путь: **Отчёты → Стандартные → Конверсии → Воронки**.

Тип всех воронок — **«Межсессионная»**: регистрация и оплата могут быть в разных визитах.

### Основная воронка (лендинг → оплата)

```
Визит на сайт (страница zeip.ru)
  → signup
    → onboarding_complete
      → checkout_started
        → payment_success_activated
```

### Воронка онбординга

```
signup
  → onboarding_step_1
    → onboarding_step_2
      → onboarding_step_3
        → onboarding_step_4
          → onboarding_complete
```

### Воронка пейволл → оплата

```
paywall_cta_buy (или banner_map_cta)
  → checkout_started
    → payment_success_activated
```

## Как добавить новую цель

1. Добавить вызов `reachYandexMetrikaGoal("goal_name", params?)` в нужном месте кода.
2. Создать цель в интерфейсе Метрики: **Цели → Добавить цель → JavaScript-событие → идентификатор**.
3. Зафиксировать ID и описание в этом файле.
