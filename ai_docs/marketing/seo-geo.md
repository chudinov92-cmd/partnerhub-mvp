## Что уже сделано в коде

### 1. Метаданные страниц (`src/app/layout.tsx`)

Раньше у сайта был только голый `title: "Zeip"` и короткое описание. Теперь:

- **Title template** — каждая страница может иметь свой заголовок, например `Карта | Zeip`, а у главной: `Zeip — карта людей, готовых делать проекты вместе`.
- **Description** — полное описание на ~160 символов с ключевыми словами и УТП.
- **Keywords** — набор поисковых фраз: «найти партнёра для бизнеса», «поиск партнёра», «единомышленники», «бизнес-партнёр», «карта предпринимателей» и др.
- **OpenGraph** — теги для красивого превью при расшаривании в соцсетях и мессенджерах (заголовок, описание, картинка 1200×630, локаль `ru_RU`).
- **Twitter Card** — аналог OG для Twitter/X.
- **Robots** — явное разрешение индексации с параметрами `max-snippet: -1`, `max-image-preview: large` (важно для попадания в сниппеты Google).
- **Canonical** — указывает поисковикам, что главная версия сайта — `https://zeip.ru`.
- **Слоты верификации** — зарезервированы мета-теги для Яндекс Вебмастера и Google Search Console (активируются через переменные окружения).

### 2. Sitemap (`src/app/sitemap.ts`)

Автоматически генерируется по адресу `https://zeip.ru/sitemap.xml`. Включены публичные маршруты:
- `/` — главная, приоритет 1.0, обновление раз в неделю
- `/map` — карта, приоритет 0.9, обновление ежедневно
- `/subscription` — подписка, приоритет 0.7
- Страницы условий (`/terms/*`) — приоритет 0.3

### 3. Robots.txt (`public/robots.txt`)

Закрыты от индексации: `/api/`, `/admin/`, `/auth/`, `/settings/`, `/profile`, `/personal-data`, `/onboarding/`. Остальное открыто. Sitemap прописан явно.

### 4. Google Analytics 4 (`src/components/GoogleAnalytics.tsx`)

Новый компонент по аналогии с уже существующей Яндекс Метрикой. Активируется только после принятия cookie-баннера. ID подключается через переменную окружения `NEXT_PUBLIC_GA_MEASUREMENT_ID`.

## GEO — Generative Engine Optimization

GEO — это оптимизация под AI-поисковики: ChatGPT Search, Perplexity, YandexGPT, Gemini и другие. В отличие от классического SEO, AI-движки читают не ключевые слова, а **структурированный контекст** — понимают, что это за сайт, чем занимается, кому полезен.

### Что сделано: JSON-LD Schema.org (`src/app/layout.tsx`)

В `<head>` каждой страницы вшит структурированный блок:

- **Organization** — имя, URL, логотип, описание бренда на русском.
- **WebSite** — название, описание, язык `ru-RU`, ссылка на поиск по карте (`SearchAction`). Это позволяет Google показывать строку поиска прямо в выдаче (sitelinks searchbox) и помогает AI-движкам понять, что Zeip — это инструмент поиска людей.
