# Экран: квиз-онбординг (`/onboarding`)

## Цель

После регистрации собрать профиль за 4 шага и вывести пользователя на карту. Скипа нет.

## Доступ

- URL: `/onboarding`, шаги `/onboarding?step=0|1|2|3`
- Без сессии → `/auth?redirect=/onboarding`
- Квиз уже пройден (`onboarding_completed`) → `/map`
- TopBar скрыт

## Макет (mobile first, 375)

- Фон: `#f6f8f7` + лёгкий emerald radial сверху
- Карточка: белая, `max-w-lg` (~512px) по центру, radius 16px, паддинг 16px (24px с `sm`)
- Десктоп: та же колонка, шире не раскладывать
- Шрифт: системный UI. Акцент `#009966`
- Кнопки 48px внизу карточки, **не sticky**. Safe area снизу
- **Footer** — общий [`LandingFooter`](../../../my-app/src/app/landing/components/LandingFooter.tsx) как на лендинге: юридические ссылки, `support@zeip.ru`, ООО «ЗЕИП». На всех шагах и состояниях (loading, ошибка сессии, форма); на коротких экранах прижат к низу viewport

Каркас: прогресс (4 сегмента) → `ШАГ N ИЗ 4` → заголовок → алерт ошибки → поля → **Далее** / **Назад**+**Далее** / **Назад**+**На карту** → footer

## Шаги

1. **Расскажите о себе** — имя*, фамилия (подпись «Видна только вам»), город*, возраст* (1–99, без ведущего нуля, макс. 2 цифры). Подсказка про слоты пионера (осталось N бесплатных Pro+ на 90 дней) скрыта, пока акция выключена в `/admin/promo`. На мобилке (`< lg`) выбор **города** — [`MobileSelectSheet`](../components/mobile-select-sheet.md) (sticky-поиск, высота от `visualViewport`).
2. **Профессия и отрасль** — статус чипами (необяз.), профессия*, отрасль*, подотрасль если есть. На мобилке **профессия / отрасль / подотрасль** — тот же bottom sheet; «Текущий статус» остаётся чипами. «Другое» у профессии → текстовое поле. Если в поиске профессии нет совпадений с каталогом — подсказка «Нет вашей профессии? Выберите «Другое»…» и пункт «Другое»; после выбора «Другое» поле ввода кастомной профессии получает фокус. Дедупликация: совпадение по `label_key` (регистр/пробелы) подставляет профессию из каталога; опечатки — inline на blur и модалка на «Далее» ([`profession-catalog-dedup.md`](../features/profession-catalog-dedup.md))
3. **Интересы и о себе** — всё необязательно. «Ищу» (несколько: идеи / проект(ы) / команду → `profiles.seeking`), «О себе» (`profiles.skills`, placeholder-пример в инпуте), «Ресурсы» (`profiles.resources`, placeholder-пример в инпуте), профессии (макс. 5 чипов). Тексты плейсхолдеров: [`profileFieldPlaceholders.ts`](../../../my-app/src/lib/profileFieldPlaceholders.ts). После квиза «Ищу», «О себе» и «Ресурсы» редактируются в [`/profile`](/profile); на карте «Ищу» фильтруется блоком **«Ищут»** в «Поиск специалистов»
4. **Ваша точка на карте** — карта ~260px, маркер = первая буква имени или «Я»

## Состояния

| Состояние | UI |
|-----------|-----|
| loading | «Загрузка…» по центру **только при первом входе** (bootstrap профиля); между шагами форма не схлопывается |
| сессия мертва / профиль не создался | ошибка + «К регистрации», не вечный спиннер |
| ошибка валидации / сети | красный алерт, кнопка активна |
| сохранение | «Сохраняем…» на кнопке «Далее», кнопки disabled; следующий шаг показывается сразу, persist идёт в фоне |
| пионер | `PioneerModal` — только если акция включена и слот выдан |
| иначе после шага 4 | `QuizCompleteModal` → `/map` |

## После перехода на карту

При **первом открытии** экрана карты (после квиза, заход на `/map` с другого экрана, переключение список → карта) камера **один раз** центрируется по **собственному пину** пользователя (обфусцированные координаты из `locations`, зум — как у выбранного города). Свой пин грузится отдельным запросом (`fetchOwnActiveLocation`), без bbox viewport — иначе на зуме города (cluster) точка не попадала в выдачу, и карта оставалась на центре города. Если точки нет — fallback на центр города **после** `currentUserReady` и завершения этого запроса. Смена фильтров, закрытие попапа и возврат с вкладки «Чаты» без размонтирования карты вьюпорт **не сбрасывают**. Смена города в шапке — `jumpTo` центра города, без повторного следования за своим пином. При deeplink `/map?profile=…` приоритет у камеры на чужой профиль.

Собственный пин на `/map` **дважды** увеличивается до hover-состояния (`scale(1.25)`) и возвращается в исходный размер; пауза между пульсами — **0,3 с**. Старт — после события `idle` карты (тайлы и камера готовы), а не сразу при `load`. Анимация повторяется при **каждом открытии карты** (заход на `/map`, переключение список → карта, возврат на вкладку «Карта» на мобилке). Смена фильтров не перезапускает её. CSS: `partner-map-pin-hello` в [`globals.css`](../../../my-app/src/app/globals.css); логика — [`PartnerMap.tsx`](../../../my-app/src/components/PartnerMap.tsx).

При смене фильтров «Поиск специалистов» **свой пин не скрывается**, даже если профиль не попадает под выбранные критерии; список «Профили» фильтруется как раньше.
