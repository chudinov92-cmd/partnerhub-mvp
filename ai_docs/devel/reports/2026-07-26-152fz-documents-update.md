## 2. Необходимые доработки проекта

### Критические (P0) — блокер для подачи заявки в РКН

#### П1. Уведомление РКН (E1) — организационная задача
- Подать уведомление об операторе ПД через [pd.rkn.gov.ru](https://pd.rkn.gov.ru/operators-registry/operators-list/)
- URL обработки: `https://zeip.ru`
- Перечень ПД: email, профессиональные данные, IP, cookie, поведенческие
- Цели: функционирование профессиональной сети, аналитика
- Третьи лица: Яндекс, VK, Робокасса

#### П2. Таблица cookie в документах (A1)
- Создать отдельную страницу `/terms/cookies` или раздел в `/terms/privacy`
- Перечислить все cookie и localStorage: `sb-*-auth-token`, `_ym_*`, `_tmr_*`, `cookie_consent`, `anonymous_uid`, `selected_city`, `zeip_push_dismissed_at`, `zeip_password_reset_complete`
- Для каждой строки: категория, назначение, срок жизни, нужно ли согласие, поставщик

#### П3. Версия cookie-политики в документе (A2)
- В `cookie.json` добавить версию `v2026.1` (совпадает с `COOKIE_POLICY_VERSION` в коде)
- Это нужно для привязки логов в `cookie_consent_logs` к актуальной версии политики

### Рекомендуемые (P1)

#### П4. SMTP-провайдер в список третьих лиц
- Выяснить, какой SMTP используется для отправки email (транзакционные письма GoTrue)
- Добавить в `privacy.json` раздел «Третьи лица»

#### П5. Описание маскировки IP в политике (C2)
- В `privacy.json` добавить явное упоминание, что IP-адрес хранится в маскированном виде (последний октет/сегмент обнуляется)

#### П6. Порядок отзыва согласия на cookie (A2)
- В `privacy.json` добавить инструкцию: как отозвать согласие (очистить localStorage, opt-out Яндекс.Метрики)

#### П7. Приказ об ответственном за ПД (E2)
- Назначить ответственного за обработку ПД (внутренний документ)
- Указать его в форме уведомления РКН

### Дополнительные (P2)

#### П8. Гранулярное согласие на cookie
- API уже поддерживает `consent_type: 'necessary_only' | 'all' | 'marketing'`
- UI-кнопки «Только необходимые» / «Принять всё» в баннере

#### П9. Экспорт данных пользователем (D2)
- Страница выгрузки профиля в JSON или инструкция про обращение на support@zeip.ru

#### П10. Политика удаления старых cookie_consent_logs (C2)
- SQL cron-задача или напоминание: удалять записи старше 3 лет
