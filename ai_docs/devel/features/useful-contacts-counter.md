# Счётчик полезных контактов в хедере

## Определение

**Полезный контакт** — в личном чате 1:1 один пользователь написал, второй ответил. Засчитывается **один раз на пару** пользователей.

**Метрика в хедере:** число **уникальных пользователей**, участвующих хотя бы в одной такой паре, в выбранном городе.

- Пара Perm–Moscow: +1 в счётчике Перми и +1 в счётчике Москвы (по `profiles.city` каждого участника).
- «Россия»: все пользователи с заполненным городом (кроме значения `Россия`), у которых есть полезный контакт.

Исключения: чаты поддержки, групповые чаты.

## БД

- Таблица `useful_contact_pairs (profile_low, profile_high, chat_id, established_at)`
- Триггер `trg_messages_useful_contact` на `messages` AFTER INSERT
- RPC `get_useful_contacts_users_count(p_city text)`

## Ограничение отправки сообщений

Пользователь без заполненных **города** и **профессии** в профиле не может отправлять личные сообщения. Показывается предупреждение со ссылкой на `/profile`. Обращения в поддержку — отдельно.
