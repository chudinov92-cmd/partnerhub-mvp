# Онбординг «Заполните профиль»

**Статус:** реализовано — плашка рядом с кнопкой профиля в TopBar на `/map` для авторизованных пользователей.

## Цель

Напомнить новому пользователю указать **город в профиле** — основной источник города для карты после входа.

## Когда показывается

На `/map`, если:

- пользователь **авторизован**;
- `profiles.city` **пуст**.

Скрывается автоматически, когда в профиле сохранён город (в т.ч. после возврата с `/profile`).

## UI

- Плашка **«Заполните профиль»** слева от кнопки аватара.
- Острый кончик справа, указывает на кнопку профиля.
- Клик → переход на [`/profile`](/profile).
- Кнопка профиля подсвечивается `ring-emerald-400`, пока плашка видна.

## Критерий «профиль заполнен»

Только наличие **города** в `profiles.city` (не профессия и не другие поля).
