# @my-startup/profile

Движок профилей: сервисы (`match`, `map`, `viewport`, `session`, `likes`, `editor`, `contacts`),
хуки (`useProfiles`, `useContacts`), справочники профессий/отраслей (`catalogs/`),
доменные типы (`types`), чистые утилиты и компонент `ProfilePreviewCard`.

Зависит от `@my-startup/auth`, `@my-startup/subscription`, `@my-startup/chat`.

## Building

Run `nx build profile` to build the library.
